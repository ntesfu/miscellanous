\chapter{Project Development}
\section{Introduction}
    Gearbox layout generation is the process of determining the number of reduction stages, 
    shaft locations, gear ratios per stage, housing dimensions, gear arrangement and positioning, 
    and bearing placement. The objectives of this process include meeting speed-reduction 
    requirements, maximizing efficiency, respecting packaging constraints, transmitting torque 
    safely, and minimizing weight.

    \begin{itemize}
        \item \textbf{Given:}\par
            P, $n_{in}$, $n_{out}$, $T_{req}$, Material specs
            Operation condition, Material, Geometric input
        \item \textbf{Determine:}\par
            $N_{stages}$, $u_{i}$, $z_{in}$, $m_{i}$, $a_{i}$, $b_{i}$, $D_{shaft}$
        \item \textbf{Subject to:}\par
            $g(x) \le 0$
        \item \textbf{Where constraints include:}\par
            Fatigue Limit and Stress Limit
        \item \textbf{Where constraints include:}\par
            Layout generation is not a sizing problem and it is a coupled topology-selection problem.
    \end{itemize}

    Traditional gearbox design philosophy relies on engineering handbooks, designer experience, 
    design standards (AGMA, ISO), and previous gearbox templates. The approach is characterized by 
    proven methodology and easy validation, but it is also time-consuming, requires expert knowledge, 
    and offers limited design exploration. So, the value of this project is to minimize those 
    constraints—reducing time consumption, lessening the need for specialized expertise, and 
    expanding design exploration—by developing an AI system as a proof-of-concept that will aid 
    engineers in estimating the optimal weight and size of the gearbox layout.

    The sizing of the helicopter main gearbox follows a reference architecture in which Stage 1 
    consists of a spiral-bevel reduction that receives power from the engines and performs a ($90^\circ\text{C}$) 
    axis redirection, while Stage 2 incorporates a five-planet planetary reduction that drives 
    the rotor-mast epicyclic stage and a fixed ring gear.

\section{Cohort Pipeline}
    The pipeline for this cohort is stated in the image below. The process begins with Python input, 
    comprising operational condition, material, and geometric data. This information is incorporated 
    into a Python script, which generates outputs that become the parameters for Romax: geometry and 
    location, number of teeth, reduction ratio, and face width. Romax then verifies whether these 
    parameters satisfy weight and sizing constraints and whether the design achieves the required 
    safety factor. The Romax output includes mass, stress analysis, the actual gear ratio, and the 
    safety factor. If the design is valid, the team proceeds to AI model input; if not, the team 
    updates and reconfigures the design script and re-runs the pipeline.

\section{Romax Concept (Student Edition)}
    Romax is the software used as a validation tool. During this time, the team used Romax Concept (Student Edition), 
    the only Romax product that offers a student edition—a trial version of the product. This helped 
    the team gain an understanding of Romax in general and facilitated progress on the project.

    Romax Concept (Student Edition) is a powerful tool for students and educators in the field of 
    machine design and power transmission systems. It offers a comprehensive suite of tools for 
    designing power transmissions, including systems of gears, shafts, and rolling-element bearings.
    
    Take note that this version has limitations in features. The following features of 
    Romax Concept are not available in the student edition:
    \begin{itemize}
        \item Importing or exporting of REXS model files into Concept
        \item The exporting of the Concept model to Romax DT model files  
        \item The New from Template and Save as Template option  
        \item The Detailed Design option of the Gear Set editor  
        \item No access to Helical Gear Design/Optimisation tools  
    \end{itemize}

    This version can specify, edit and model Gears using a Loading Design or Concept Design only. 
    Also, it can load designs created with Romax Concept Student Edition only.
